Daily releases from 0.5.4 to 1.0

Roadmap

0.5.4 is current: default plan scans report creates and updates, 541 built-in CKV policies, opt-in plan JSON, SARIF paths for code scanning, and sensitive plan redaction. The daily release is a patch. A minor closes a milestone. 1.0.0 waits for the exit criteria. Checkboxes live in ROADMAP.md.

Latest patch: plan scan scope (#80) shipped in 0.5.4. Next open 0.6.0 work is plan graph edges.

A patch (0.x.Y) is a fix, a false positive, speed, docs, hardening, or one new check. A minor (0.X.0) closes the open milestone or adds a framework, an output format, or a scan mode. No CVE database on any path.

Already in 0.5.2

541 checks (Docker attribute ids 11/11, Kubernetes 106/113, Terraform CKV_AWS_* resource ids 341/361). CI benchmark regression gate on pull requests. CLI, JSON, SARIF, and JUnit. GitHub Action, pre-commit, Homebrew, GHCR, crates.io. Linux and macOS release archives.

1.0.0 exit criteria

  • 0.5.2 CLI flags and exit codes 0, 1, and 2 are unchanged. New flags are documented.
  • JSON, SARIF 2.1.0, and JUnit have golden files. SARIF paths are relative to the scan root.
  • Library semver and MSRV are written down, rust-version is set, and CI compiles with that toolchain.
  • Docker attribute ids stay at 100%. Kubernetes attribute ids reach 100% after documented divergences. The 25 missing AWS resource ids are implemented or named as exclusions.
  • Plan scans default to create and update, keep sensitive redaction, and expand local modules with no network. Helm and Kustomize render with no implicit remote fetch. --baseline can hold a fixture at exit 0.
  • SECURITY.md and CONTRIBUTING.md exist. cargo test --workspace, fmt, and clippy -D warnings are green. Every built-in policy still has pass and fail fixtures.
  • The CI benchmark compares the 1.0 commit to main on the same runner. No unexplained regression over 15%. A result over 5% is a warning. ACTION.md and the release workflow list the same OS and architecture pairs.

Azure, GCP, extra output formats, Windows, secret patterns, and the compliance filter are scheduled and do not block the 1.0 tag except where the criteria above name them. Full Checkov parity for those catalogs is later patch work.

Parked, and out of scope

Not milestones: Ansible, ARM, Bicep, Serverless, OpenAPI, SAM, CDK, GitHub Actions workflow checks, GitLab CI checks, other CI systems, Argo, and the smaller clouds in the Terraform snapshot (Alibaba, Yandex, OCI, NCP, Palo Alto, Tencent, Linode, DigitalOcean, OpenStack, Okta). Live cluster scanning stays deferred.

Out of scope: image and filesystem CVEs, vulnerability databases, license feeds, and SBOM output. Use Trivy for those.
