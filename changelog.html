Changelog

0.5.5 — 2026-11-19

Added

  • Terraform plan scans follow depends_on and address references (including configuration references after Terraform resolves names). Companion CKV2_* checks run on those edges (#81).
  • A string that only matches another resource's name is not a graph edge. Unchanged companions stay out of the default scan; --plan-scope all still includes them.

Changed

  • Catalog remains 541 checks. Workspace crates and Action default version pin are 0.5.5.

0.5.4 — 2026-11-19

Fixed

  • Default terraform_plan scans report only resources this apply creates or updates (including replace). Attributes come from resource_changes[].change.after (#80).
  • --plan-scope all keeps the previous whole-state plan scan.

Changed

  • Unknown plan leaves still do not fail the process. Sensitive values stay redacted.
  • Workspace homepage is the project site; Cargo manifest warnings on publish are cleared (#85).
  • Workspace crates and Action default version pin are 0.5.4.

0.5.3 — 2026-11-18

Fixed

  • SARIF artifactLocation.uri values are relative to the scan root with %SRCROOT% for GitHub code scanning (#84).
  • SARIF messages use the check name only; rule helpUri links to Checkov or the product site.

Changed

  • Workspace crates and Action default version pin are 0.5.3.

0.5.2 — 2026-11-18

Added

  • CI benchmark regression gate on pull requests and main: same-runner comparison, medians in the job summary and sticky PR comment, warn at 5% / fail at 15% (#89).
  • Five Terraform AWS checks: IAM role assume scope, S3 policy lockout guard, Session Manager encryption and logging, classic ELB TLS policy hardening.

Changed
