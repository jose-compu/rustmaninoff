Changelog

0.4.0 — 2026-11-02

Added

  • Catalog depth: 536 built-in checks. Docker 100% and Kubernetes 93.8% of pinned Checkov ids.
  • Reproducible benches (benchmarks/, scripts/bench.sh, benchmarks/history.json).
  • Checkov comparison CI and published fidelity table.

Changed

  • Workspace crates are 0.4.0.
  • Published corpus medians: Rustmaninoff 54 ms, Checkov 3.3.21 3.50 s (~65×), Trivy 0.74.0 6.27 s (~116×).

0.3.0 — 2026-11-02

Added

  • Resource graph IR (Edge, EdgeKind, ResourceRef) on ParseOutput.
  • Static edge emission from Terraform, CloudFormation, and Kubernetes.
  • Graph policy dialect cond_type: connection (plus filter alias) and evaluate_graph second pass.
  • First-wave Terraform CKV2_AWS_* checks — 185 built-in policies total.
  • Terraform variable / local evaluation: defaults, TF_VAR_*, repeatable --var-file, same-file locals.
  • OpenTofu .tofu / .tofu.json treated as Terraform HCL.

Changed

  • Workspace crates are 0.3.0 on crates.io.
  • Attribute fast path unchanged; graph checks run as a separate pass.

0.2.0 — 2026-10-15
